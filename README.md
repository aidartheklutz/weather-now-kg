# ПОГОДА ВОТ ЩАС (Weather Now KG)

A simple weather web app that shows current weather for cities in Kyrgyzstan.

Built to practice working with APIs and basic UI design. It fetches real-time weather data and displays it in a clean, easy-to-use interface.

## Features

- Current weather for most cities in Kyrgyzstan  
- Real-time data from a weather API  
- Simple, responsive design  

## Tech Stack

- React  
- JavaScript  
- OpenWeather API  
- CSS  

## Purpose

Small practice project to learn API integration and frontend basics.
